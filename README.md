# 🧠🛡️ تطبيق حماية الدماغ من التعفن الدماغي 🛡️🧠

تطبيق موبايل يساعدك تحمي دماغك من البرين روت والتعفن الدماغي بنصائح عملية ومفيدة.

## المميزات

- 10 نصائح علمية لحماية الدماغ
- عداد تقدم تفاعلي
- مؤشر صحة الدماغ
- تصميم ريسبونسف لكل أحجام الشاشات
- انيميشن سلس بين الصفحات
- واجهة باللغة العربية

## كيفية التشغيل

1. تثبيت المكتبات:
```bash
npm install
```

2. تشغيل التطبيق:
```bash
npm start
```

3. استخدم تطبيق Expo Go على تليفونك وامسح الـ QR code

## النصائح المتضمنة

- قراءة الكتب الحقيقية
- ممارسة الرياضة
- تعلم مهارات جديدة
- تقليل وقت السوشيال ميديا
- التفاعل الاجتماعي الحقيقي
- النوم الصحي
- التأمل واليقظة الذهنية
- الأكل الصحي
- الكتابة والتعبير
- الاستماع للموسيقى الهادية

## التقنيات المستخدمة

- React Native
- Expo
- Linear Gradients
- Haptic Feedback
- Responsive Design
